# Nexo Events

Free event registration and QR ticketing — the open source events tool of the Nexo ecosystem. Create an event, share the page, attendees register with just an email and get a QR ticket; validate entry at the door from your phone. Self-hostable, cookieless, privacy by design.

Status: Phase 0 (planning) — awaiting Gate 0 sign-off; next step is Phase 1 (foundation & organizer core), starting with its SPEC.
